## 3. 하드웨어 검증 결과

`docs/hardware-check.md`에 새로 확인한 항목:

- micro:bit가 Chrome Web Serial 포트 목록에 보이고 연결됨
- 통신 속도(baud rate) **115200**
- 웹 → micro:bit `PING` → `PONG` 왕복 확인
- micro:bit → 웹 한 줄 응답 수신 확인 (`TICK` 65회 이상 빠짐없이 수신)
- 외부 어댑터(DC 7.5V 3A) 연결 상태에서 서보 5개 동시 동작 확인 (`OPEN`·`FIST`). USB 전원만으로는 시험하지 않음
- **손모양 7종 모두 재현 확인**: `ROCK`, `PAPER`, `THUMB`, `INDEX`, `V`, `THREE`, `FOUR` → STEP 1·STEP 4에서 빼야 할 손모양 없음
- 서보 1~5번(엄지~새끼) 개별 동작 확인
- 로봇 → 웹 `DONE,OPEN`·`DONE,FIST`·`DONE,S` 응답 수신 확인
- **서보 속도 조절 가능**: 서보 명령의 이동 시간(ms)으로 조절 (500ms·2000ms 확인) → `SPEED,SLOW` 구현 가능
- **주의: micro:bit 시리얼 통로가 하나뿐**. 확장보드는 P12·P8 시리얼로 서보 명령을 받으므로, 명령 때만 통로를 확장보드로 돌렸다 USB로 되돌리는 방식으로 동작 확인. 공식 확장의 `Initialize StartbitV2` 블록은 쓰지 않는다
- 손모양 7종의 서보 각도표는 `docs/hardware-check.md` "3. 손모양"의 정리 표에 기록 (STEP 1·STEP 4 참고)
- 테스트 방법(MakeCode 테스트 코드, 터미널 설정, 명령어)은 `docs/hardware-check.md` 부록 1·2에 기록
