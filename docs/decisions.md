# 결정 사항

2026-11-13까지 팀이 확정한 내용. 새로 정하거나 바꾸면 날짜와 함께 이 문서를 고친다.
자세한 근거·측정 결과는 각 항목의 "관련 문서"를 본다.

## 1. 시연 형태

- 로봇손 앞에 두는 **전용 스테이션**으로 시연한다.
  - 라즈베리파이 5 + Touch Display 2 (7인치, 보드는 디스플레이 뒷면에 붙임) + Active Cooler
  - 웹캠: 로지텍 C270
  - USB 스피커폰: 자브라 스피크 510
- 전원을 켜면 Chromium **키오스크 모드**로 앱이 전체 화면으로 자동 실행된다.
  - 시크릿 모드(`--incognito`)는 쓰지 않는다. 활동 기록을 유지하기 위해서다.
- 스테이션은 **인터넷 없이** 동작한다.
  - 앱은 라즈베리파이 로컬에서 실행한다.
  - MediaPipe wasm·모델과 글꼴도 로컬에 둔다.
- 난이도와 설정은 대시보드에서 조정한다.

관련 문서: `README.md` "라즈베리파이 준비", `docs/hardware-check.md` 5번 (라즈베리파이 FPS·GPU 측정)

## 2. 미션맵 배치

- AIHand는 세워서 두고, 웹캠은 로봇 받침대 바로 앞에 둔다.
- 손 인식과 카드 보여 주는 자리는 **로봇 앞 같은 위치 한곳**이다. 웹캠과 WonderCam이 같은 자리를 본다.
- 숫자 카드는 **WonderCam 숫자 인식 모드**로 읽는다 (AprilTag 태그 방식이 아니다).
- 색깔 카드(STEP 3)는 AprilTag 태그 모드(펌웨어 F2)로 읽는다. 임시 결정이며 종이 카드로 확인한 뒤 확정한다 (#17).

관련 문서: `docs/hardware-check.md` 4번·부록 8 (숫자 인식 확신도·거리)

## 3. 시연 코스

- 순서: **손운동(STEP 4) → 가위바위보(STEP 2) → 숫자 기억(STEP 1) → 색깔손(STEP 3)**
  - 이유: 손으로 하는 활동 → 카드로 하는 활동 (입력 방식이 한 번만 바뀐다), 쉬운 것 → 어려운 것
- STEP 번호와 폴더명(`step1-memory` 등)은 바꾸지 않는다. 화면에는 코스 순서("1번째 활동")로 보여 준다.
- 시너지 설명
  - 순서 자체의 이유 (위)
  - 활동마다 다른 역할

    | 활동 | 역할 |
    |---|---|
    | 손운동 | 모방·움직임 |
    | 가위바위보 | 조건 판단 |
    | 숫자 기억 | 순서 기억 |
    | 색깔손 | 주의 전환 |
- **보류** (지금 범위에서 뺌)
  - 손모양 이어지기 (앞 활동의 손모양이 뒤 활동에 다시 나오기)
  - 오늘의 손모양 회상 (코스 처음에 보고 끝에 떠올리기)
  - 앞 결과로 다음 활동 맞춤 조정

## 4. 기록과 보호자 앱

- 스테이션 결과 화면
  - 날짜별 코스 기록
  - 활동별 완료 수
  - 반응 시간 변화
  - **손 유지 시간 지표는 넣지 않는다.**
- 보호자·복지사용 폰 앱(PWA) 연동
  - 스테이션의 QR로 한 번 연결한다.
  - 코스가 끝나면 요약을 자동으로 보낸다. 인터넷이 없으면 대기열에 쌓았다가 연결되면 보낸다.
  - 클라우드는 Supabase.
  - 담당 미정, **11/26 점검 전까지** 목표 (2026-11-13 변경, 처음에는 3회차 멘토링 전까지). 점검에서 코스가 끝나면 요약이 전송되는 것까지 보여 준다.
- 개인정보
  - 사용자 이름 등 개인정보는 받지 않는다.
  - 기록은 시각 기반 ID로, 보호자 앱은 연결 코드로만 묶는다.
- 어르신은 폰을 조작하지 않는다.

## 5. 음성

- 먼저 **음성 안내** 기능을 넣는다.
  - 라즈베리파이 Chromium에 한국어 음성이 없으면 미리 녹음한 음성 파일로 바꾼다.
- 시간이 남으면 **간단한 소통**(네, 아니요, 다시 같은 몇 단어)을 인터넷 없이 연결한다.

## 6. 표현 원칙

- "치매 예방", "인지 기능 향상", "효과", "치료" 같은 표현을 앱과 발표에 쓰지 않는다.
- 화면에는 평가·진단처럼 보이는 말 대신 "활동 기록"으로만 표현한다.
- 근거 자료: `docs/research/evidence.md` (발표에서 쓸 수 있는 문장 / 쓰면 안 되는 표현 포함)
