색깔 카드 인쇄와 사용 방법

빨강 · ID 1 파랑 · ID 2 노랑 · ID 3 초록 · ID 4

1. 인쇄

  1. 컬러 프린터, A4, 배율 100% (실제 크기), 여백 없음 또는 최소
  2. "배경 그래픽" 또는 "배경색 인쇄"를 켭니다 (끄면 색이 안 나옵니다)
  3. 작은 카드만: 1쪽 · 양면: 1~2쪽을 "긴 쪽으로 넘기기" · 시연용 큰 카드: 3~4쪽
  4. 두꺼운 종이(180g 이상)를 권장합니다. 얇으면 뒷면 색이 비쳐 색이 달라집니다
  5. 코팅은 무광으로. 반짝이면 빛 반사로 흰색처럼 보여 인식이 끊깁니다

2. 로봇(WonderCam)에 색 다시 학습시키기 (꼭 이 카드로)

  1. WonderCam을 Color Recognition(색상 인식) 화면으로 바꿉니다
  2. 시연할 자리의 조명에서, 카드를 카메라 앞 15~20cm에 정면으로 듭니다
  3. 화면 가운데 + 표시를 색 정사각형 한가운데에 맞추고 흰 테두리가 색을 잡으면 학습합니다
  4. 번호는 위 표와 같게: 빨강 1, 파랑 2, 노랑 3, 초록 4
  5. Color Range(색 범위)는 공식 권장값 20으로 둡니다. 너무 크면 화면 전체가 잡히고, 너무 작으면 색의 일부만 잡힙니다. 바꾼 뒤에는 다시 학습해야 합니다
  6. 주변이 어두우면 WonderCam 보조등(Fill Light)을 켭니다. 학습할 때와 시연할 때 밝기를 같게 둡니다
  7. 학습한 뒤 카드를 바꿔 가며 다른 색으로 잘못 잡히지 않는지 확인합니다
근거: Hiwonder WonderCam 공식 문서 2.1 Color Recognition, AiHand 6.11. 모니터에 띄운 색이나 다른 종이로 학습하면 이 카드의 색과 달라서 잘 안 잡힐 수 있습니다. 빨강이 사람 피부나 옷까지 잡으면, 빨강만 이 카드로 다시 학습해 주세요.

3. 보여 주는 방법

  • 흰 부분(이름 쪽)을 잡고 색 정사각형을 카메라 정면 15~20cm에 보여 줍니다. 손가락이 색을 가리면 인식이 약해집니다
  • 한 번에 카드 한 장만 보여 줍니다. 나머지 카드는 카메라에 보이지 않게 둡니다
  • 다음 문제에서는 카드를 한 번 내렸다가 다시 보여 줍니다 (계속 들고 있으면 다시 알려 주지 않습니다)
  • 시연자는 빨강·파랑·노랑·초록이 크게 들어간 옷을 피하고, 카메라 뒤에도 이 색 물건을 두지 않습니다
