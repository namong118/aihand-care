# 코스 끝 "오늘의 한마디" (오프라인 AI)

코스가 끝나면 요약 화면의 **"로봇의 오늘의 한마디"** 칸에 따뜻한 마무리 인사가 나온다.
라즈베리파이 **안에서** 도는 작은 언어 모델(LLM)이 만든다. 인터넷을 쓰지 않고, 어르신 정보가 기기 밖으로 나가지 않는다.

## 원칙

| 원칙 | 어떻게 지키나 |
|---|---|
| 라즈베리파이 열 | **손 인식을 쉬는 때만** AI 를 쓴다. 손 인식은 활동(프로그램) 화면에서만 하고 다른 화면에서는 쉰다 (`devices.hand.rest`, 웹캠 영상은 켜 둔 채 인식 계산만 멈춤). AI 를 부르기 직전에 `isResting()`을 한 번 더 확인한다. 답은 짧게(`max_tokens` 80) |
| 지어낸 건강 조언·효과 금지 | AI 답에 **금지어**(`src/ai/greeting-logic.js`의 `BANNED_WORDS`)가 하나라도 있으면 버린다: 건강·치매·예방·치료·효과·개선·향상·기억력·두뇌·뇌·근력… 그리고 점수·정답·실패·잘하셨… 같은 평가 말. 숫자·영어·한자가 섞여도 버린다 |
| AI 에게 주는 정보 | 함께한 **활동 이름**, 모두 했는지, 호칭만. 완료 수·반응 시간 같은 숫자는 주지 않는다 (평가처럼 말할 수 있어서) |
| 멈추지 않기 | AI 서버가 없거나(노트북·배포 주소), 15초 안에 답이 없거나, 답을 버리면 **미리 써 둔 인사**(`FALLBACK_GREETINGS`)를 쓴다. 미리 써 둔 인사도 금지어 검사를 통과하는지 테스트한다 |

## 구조

```
코스 끝 (main.js finishCourse)
  → makeCourseGreeting (src/ai/greeting.js)
      손 인식 쉬는 중? ── 아니오 → 미리 써 둔 인사
      예 → askLlm: POST /ai/v1/chat/completions (src/ai/llm.js)
             → Vite 서버가 127.0.0.1:8080 으로 넘김 (vite.config.js, dev·preview 둘 다)
             → llama-server (라즈베리파이 안)
      답 다듬기(cleanGreeting) → 검사(checkGreeting) → 통과하면 AI 인사, 아니면 미리 써 둔 인사
  → 요약 화면 "로봇의 오늘의 한마디" 칸 (course.js setGreeting)
```

## 라즈베리파이에 AI 서버 설치 [검증 필요]

시연 스테이션: 라즈베리파이 5 **8GB** (2026-11-24 확인). 2B급 모델(4비트, 약 1.5GB)이 넉넉히 들어간다.
**설치·모델은 팀(A) 확인 뒤** 진행한다. 아래는 계획이다.

1. llama.cpp 빌드 (`llama-server` 실행 파일)
2. 한국어 소형 모델(GGUF, 4비트 `Q4_K_M`) 하나 고르기. 후보 (라이선스 확인 필요):
   - 카카오 **Kanana Nano 2.1B** instruct
   - LG **EXAONE 3.5 2.4B** instruct (비상업 조건)
3. 실행 (같은 기기에서만 받도록 `127.0.0.1`):
   ```bash
   llama-server -m 모델.gguf --host 127.0.0.1 --port 8080 -c 1024 -t 3
   ```
   - `-t 3`: 4코어 중 3개만 써서 화면·브라우저가 버벅이지 않게 (실측 후 조정)
   - 키오스크와 함께 켜지게 하려면 `scripts/kiosk.sh`(A) 또는 systemd 서비스에 넣는다
4. 확인할 것: 인사 한 번 만드는 시간(목표 10초 안), 그동안 온도(`vcgencmd measure_temp`), 한국어 품질, 금지어에 걸려 버려지는 비율 (브라우저 콘솔 `[AI 인사]`)

## 노트북 시험 결과 (2026-11-24, D)

- 모델: 카카오 **Kanana 1.5 2.1B instruct** (Apache 2.0), 4비트 `Q4_K_M` 1.45GB (Hugging Face `DevQuasar/kakaocorp.kanana-1.5-2.1b-instruct-2505-GGUF`)
- 서버: llama.cpp `b12667` Windows CPU, `-c 1024 -t 3`. 모델 불러오기 약 10초
- 상황 3가지(모두 함께 + 호칭 / 모두 함께 + 손님 / 일부 건너뜀) × 4번 = 12번
  - **금지어 검사 통과 12/12**. 시간 중간값 **4.7초**, 최대 14초(첫 번째, 준비 시간)

  - 햇살님, 오늘 손운동, 가위바위보, 숫자 기억, 색깔손 모두 함께해 주셔서 고마워요. 즐거우셨길 바랍니다.
  - 오늘도 햇살처럼 밝고 따뜻하게 활동해 주셔서 고마워요. 즐거웠던 시간, 다음에도 꼭 함께 해요!
  - 단풍님, 오늘 손운동과 가위바위보 활동 함께해 주셔서 고마워요. 즐거웠길 바랍니다.
