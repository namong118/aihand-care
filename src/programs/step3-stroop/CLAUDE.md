# STEP 3 색깔손 (step3-stroop)

- **담당:** C
- 이 폴더 밖 파일은 고치지 않는다. 필요하면 이유를 설명하고 담당 A에게 확인받는다.

## 목적

색 이름 글자(예: "파랑")를 다른 색(예: 빨간색)으로 보여주고,
글자의 **뜻이 아니라 글자 색**에 맞는 색 태그를 고르는 활동 (스트룹 과제 형식).
교육·체험용 활동이며, 치료·예방 효과를 주장하지 않는다.

## 입력

- **색 태그:** `ctx.tag.onTag(cb)` → `cb({ id })`, id는 `data/tags.json`의 `RED`·`BLUE`·`YELLOW`·`GREEN`
  - Mock: 키보드 `R`/`B`/`Y`/`G` 또는 오른쪽 Mock 패널 버튼
  - 실제: WonderCam 태그 인식 → micro:bit → `TAG,<ID>` **[검증 필요]** WonderCam이 태그 ID를 넘길 수 있는지 아직 확인 전
- **화면 버튼:** 태그 인식이 안 될 때를 위한 대체 입력. 색 막대와 함께 "빨강" 같은 글자를 꼭 표시한다

## 해야 할 기능

- [x] 문제 만들기 `makeQuestion` (쉬움: 뜻=색, 보통: 섞임, 어려움: 항상 다름), 판정 `judge` (테스트 있음)
- [x] 문제 1개 → 입력(태그 또는 화면 버튼) → 판정 → 로봇 반응 → 기록
- [ ] 한 회차 여러 문제, 문제 사이 간격
- [ ] 색 구분이 어려운 사용자를 위한 안내 (아래 참고)
- [ ] 로봇의 역할 정하기 (예: 문제 시작 신호, 정답 색 태그 가리키기 등. 가능한 동작은 `docs/hardware-check.md` 확인 후)

## 접근성 메모

이 활동은 색 자체를 보는 과제라서 문제 글자는 색으로만 구분된다. 대신:

- 답하는 버튼·태그에는 항상 색 이름 글자를 함께 쓴다.
- 노랑이 잘 보이도록 글자는 어두운 배경(`.stroop-stage`) 위에 표시한다.
- 시작 전에 "색 구분이 어려우시면 다른 활동을 골라도 돼요" 같은 안내를 넣을지 팀에서 정한다.
