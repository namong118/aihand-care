# STEP 1 기억손 (step1-memory) — 숫자 순서 기억

- **담당:** A
- 이 폴더 밖 파일은 고치지 않는다. 필요하면 이유를 설명하고 확인받는다.

## 목적

로봇이 손가락으로 **숫자를 차례로 보여준 뒤 손을 내리면**, 사용자가 **기억해서** 같은 순서로 숫자 카드를 하나씩 WonderCam에 보여주는 활동.
교육·체험용 활동이며, 치료·예방 효과를 주장하지 않는다.

- 숫자 카드: 인쇄하지 않고 **AIHand 교구에 들어 있는 숫자 카드(1~5, 숫자마다 한 장)**를 그대로 쓴다.
- 숫자 ↔ 로봇 손모양 (`logic.js`의 `POSE_BY_NUMBER`, `data/poses.json`에 있는 것만):

| 숫자 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 손모양 | `INDEX` | `V` | `THREE` | `FOUR` | `PAPER` |

## 흐름

1. 화면을 열 때 `ctx.card.onNumber`를 구독한다 → core가 WonderCam을 숫자 모드로 바꾸기 시작한다
2. "시작하기" → `await ctx.card.ready()`로 숫자 모드가 된 다음 진행한다 (보통 바로, 최대 약 5초)
3. 로봇이 숫자를 차례로 보여준다 (`showPose`) → 손을 내린다 (`rest`)
4. 사용자가 숫자 카드를 같은 순서로 하나씩 보여준다. 화면 숫자 버튼 1~5로도 입력할 수 있다
5. 판정 → 로봇 반응 (`react('ok' | 'retry')`) → 기록

## STEP 1과 STEP 4의 차이

| | STEP 1 기억손 | STEP 4 손운동 코칭 |
|---|---|---|
| 핵심 | **기억 후 재현** | **보면서 반복** |
| 로봇 | 숫자를 보여준 뒤 손을 내린다(`rest`). 사용자가 답할 때는 정답이 안 보인다 | 시범 동작을 보여주는 동안 사용자가 동시에 따라 한다 |
| 입력 | 숫자 카드(WonderCam) 또는 화면 숫자 버튼 | 손 인식(웹캠) 또는 화면 버튼 |
| 판정 | 순서·숫자가 맞았는지 (정답 / 다시 해 볼까요) | 따라 했는지만 센다 (완료 / 건너뜀). 맞고 틀림을 따지지 않는다 |
| 기록 | `done` = 정답 문제 수 | `done` = 따라 한 동작 수, `skipped` = 건너뛴 수 |

두 프로그램의 코드가 비슷해 보여도 합치지 않는다. 목적이 다르다.

## 입력 확정 기준

- `ctx.card.onNumber`로 들어온 숫자 하나 = 입력 하나. 따로 유지 시간을 재지 않는다
  - 펌웨어가 이미 "보이는 숫자가 바뀔 때만 한 번" 알려 준다 (확신도 기준 `MIN_CONF`도 펌웨어에서 거른다)
  - 같은 카드를 들고 있으면 다시 들어오지 않는다. 그래서 화면에 "카드를 하나 보여 준 뒤에는 내려 주세요"라고 안내한다
- 화면 숫자 버튼 1~5: 카드 대신 입력 (손이 불편하거나 카드가 안 읽힐 때)
- 입력 단계가 아닐 때(로봇이 보여주는 중 등) 들어온 카드는 버린다
- "처음부터 다시": 이번 문제의 입력을 모두 비우고 첫 번째부터 다시 받는다 (로봇은 다시 보여주지 않는다)
- 손 인식(`ctx.hand.waitForPose`)은 STEP 1에서 쓰지 않는다
- 숫자 순서: 한 문제 안에서 **같은 숫자는 두 번 나오지 않는다** (카드가 숫자마다 한 장뿐)
- 난이도: 쉬움 1개, 보통 2개, 어려움 3개 (바꿀지는 따로 정한다)

## 기록 (`ctx.log.record`)

공통 필드 + `detail: { difficulty, expected, given, matched, inputVia }`

- `expected`, `given`: 숫자 배열 (예: `[3, 1]`)
- `matched`: 자리까지 맞은 개수
- `inputVia`: 입력마다 `'card'`(숫자 카드) 또는 `'button'`(화면 버튼)
- "처음부터 다시"를 누르면 그 전 입력은 기록하지 않는다. 반응 시간도 다시 잰다

## 하지 말아야 할 것

- `src/core/`를 import 하거나 고치지 않는다. **`ctx`만 사용한다.**
- `logic.js`에서 DOM이나 `ctx`를 쓰지 않는다.
- 입력 단계에서 정답 숫자를 화면에 보여주지 않는다. 로봇이 보여주는 동안에도 화면에 숫자를 쓰지 않는다.
- "틀렸습니다", "실패" 대신 "다시 해 볼까요?"를 쓴다. 기억력 점수처럼 보이는 표현을 쓰지 않는다.
