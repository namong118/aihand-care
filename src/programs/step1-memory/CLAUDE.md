# STEP 1 기억손 (step1-memory)

- **담당:** A
- 이 폴더 밖 파일은 고치지 않는다. 필요하면 이유를 설명하고 확인받는다.

## 목적

로봇이 손모양을 차례로 **보여준 뒤 손을 내리면**, 사용자가 **기억해서** 같은 손모양을 같은 순서로 만드는 활동.
교육·체험용 활동이며, 치료·예방 효과를 주장하지 않는다.

## STEP 1과 STEP 4의 차이

| | STEP 1 기억손 | STEP 4 손운동 코칭 |
|---|---|---|
| 핵심 | **기억 후 재현** | **보면서 반복** |
| 로봇 | 보여준 뒤 손을 내린다(`rest`). 사용자가 따라 할 때는 정답이 안 보인다 | 시범 동작을 보여주는 동안 사용자가 동시에 따라 한다 |
| 판정 | 순서·손모양이 맞았는지 (정답 / 다시 해 볼까요) | 따라 했는지만 센다 (완료 / 건너뜀). 맞고 틀림을 따지지 않는다 |
| 기록 | `done` = 정답 문제 수 | `done` = 따라 한 동작 수, `skipped` = 건너뛴 수 |

두 프로그램의 코드가 비슷해 보여도 합치지 않는다. 목적이 다르다.

## 해야 할 기능

- [x] 손모양 순서 만들기 `makeSequence` (같은 모양 연달아 안 나옴), 판정 `judgeSequence` (테스트 있음)
- [x] 문제 1개 → 로봇이 보여주기 → 손 내리기 → 사용자 재현(손 인식 또는 화면 버튼) → 판정 → 로봇 반응 → 기록
- [ ] 한 회차 여러 문제, 맞히면 다음 문제 길이 늘리기 등 진행 규칙
- [ ] 쓸 손모양 범위 정하기: AIHand가 실제로 만들 수 있는 손모양만 (`docs/hardware-check.md` 확인 후)
- [ ] 입력 중 "처음부터 다시" 버튼

## 입력 확정 기준 (지금 값)

- `ctx.hand.waitForPose({ holdMs, since })`로 한 개씩 받는다 (화면 버튼과 `Promise.race`)
- 이름 있는 손모양을 **1초**(속도 "천천히"면 1.5초) 유지하면 한 개 확정
- `since` = 입력 시작 시각, 또는 바로 앞 입력이 확정된 시각. 그 뒤에 만든 손모양만 인정
- 난이도: 쉬움 1개, 보통 2개, 어려움 3개

## 기록 (`ctx.log.record`)

공통 필드 + `detail: { difficulty, expected, given, matched, inputVia }` (`inputVia`는 입력마다 `'hand'` 또는 `'button'`)

## 하지 말아야 할 것

- `src/core/`를 import 하거나 고치지 않는다. **`ctx`만 사용한다.**
- `logic.js`에서 DOM이나 `ctx`를 쓰지 않는다.
- 입력 단계에서 정답 손모양을 화면에 보여주지 않는다.
- "틀렸습니다", "실패" 대신 "다시 해 볼까요?"를 쓴다. 기억력 점수처럼 보이는 표현을 쓰지 않는다.
