# 도전 활동: 21 게임 (challenge-21)

- **담당:** A
- 이 폴더 밖 파일은 고치지 않는다. 필요하면 이유를 설명하고 확인받는다.
- 기본 활동 **가위바위보(STEP 2)의 짝**. 같은 도구(웹캠 손 인식)로 한다. 홈의 가위바위보 카드 아래 "도전" 칸에서 연다 (`dashboard/catalog.js` `CHALLENGES`, #132). **코스에는 들어가지 않는다**

## 목적

1부터 사용자와 로봇이 번갈아 수를 이어 센다. 한 번에 몇 개를 셀지 손가락 개수로 보여 준다.
**끝 숫자를 부르게 되는 쪽이 그 판을 내준다.** 앞을 내다보고 개수를 골라야 해서 기본 활동보다 오래 생각한다.
교육·체험용 활동이며, 치료·예방 효과를 주장하지 않는다.

- 사용자가 늘 먼저 한다
- 판마다 **끝 숫자**와 **한 번에 셀 수 있는 개수**가 무작위로 바뀐다 (방법 하나를 외워서 풀리지 않게)
- 사용자가 끝까지 잘 두면 늘 이길 수 있는 판만 만든다 (`makeGame`: 처음 자리가 지는 자리가 아닌 끝 숫자만)
- 이기는 방법: 내 차례를 끝 숫자에서 (개수 + 1)씩 거꾸로 센 수에서 끝낸다 (`goodSpots`, 예: 끝 20, 3개씩 → 3·7·11·15·19)

## 단계 (시작 화면에서 고름, 공통 부품 `src/ui/level-picker.js`)

| 단계 | 끝 숫자 | 한 번에 | 로봇 | 도움 |
|---|---|---|---|---|
| 1단계 | 15~20 | 1~3개 | 이기는 수를 30%만 고름 | 로봇이 이긴 판 끝 화면에 "내 차례를 3, 7, 11…에서 끝내 보세요" |
| 2단계 | 18~25 | 1~2개 또는 1~3개 | 70% | 없음 |
| 3단계 | 20~25 | 1~3개 또는 1~4개 | 늘 이기는 수 | 없음 |

- 로봇은 이기는 수를 고르지 않을 때도 끝 숫자는 피할 수 있으면 피한다 (일부러 지지 않음, `robotCount`)
- 미리 고른 단계: `ctx.settings.challengeLevel`(1·2·3)이 있으면 그 단계, 없으면 1단계 (`defaultLevel`). "나의 시작 찾기"와 함께 대시보드가 넣을 예정
- `ctx.settings.difficulty`(기본 활동용)는 쓰지 않는다. 속도 느리게(`SLOW`)는 손 확정 시간·로봇이 생각하고 보여 주는 시간만 늘린다

## 흐름 (한 회차 = 한 판)

1. 단계 고르기 → 이번 판 안내("이번 끝 숫자는 20이에요") → "시작하기" → 로봇 인사(`hello`)
2. 내 차례: 1~끝 숫자 칸(누가 셌는지 "나"/"로봇" 글자로도 표시), 개수 버튼 1~maxStep(버튼에 셀 수를 함께 씀), "그만하기"
3. 손가락 개수(웹캠) 또는 버튼 → 그만큼 이어 셈. 끝 숫자를 부르면 로봇이 가져감
4. 로봇 차례: "로봇이 생각하고 있어요" → 로봇이 손가락으로 개수(`showPose`) + 화면에 "로봇: 2개 — 9, 10" → `rest`
5. 로봇이 끝 숫자를 부르면 칭찬(`react('ok')`)
6. 끝 화면: "한 판 더 하기"(새 끝 숫자) / "단계 바꾸기". 기록 한 번

## 입력 확정 기준

- `ctx.hand.waitForPose({ holdMs, since: 내 차례가 시작된 시각, names })`
- 손가락 개수: 검지 하나 `INDEX` = 1, 브이 `V` = 2, 셋 `THREE` = 3, 넷 `FOUR` = 4 (웹캠 7종 인식 확인됨, `docs/hardware-check.md`). 로봇도 같은 손모양으로 개수를 보여 준다
- `names`는 **이번에 셀 수 있는 개수만** (끝 숫자를 넘는 개수는 받지 않음)
- 1초 유지(느리게 1.5초). 차례 전부터 들고 있던 손은 인정하지 않는다 (공통 규칙)
- 손 인식 상태 한 줄: 개수 손모양이 보이면 "손가락 둘 보여요 — 그대로 잠깐 있어 주세요", 다른 손모양이면 "검지부터 손가락을 펴서 개수를 보여 주세요"

## 기록 (`ctx.log.record`)

판이 끝날 때 한 번. 끝까지 하지 않은 판(중간에 화면을 닫음)은 기록하지 않는다.

- 공통 필드: `total` 1, `done` 로봇이 끝 숫자를 부르면 1, `skipped` "그만하기"면 1, `avgReactionMs` 내 차례마다 개수를 고르는 데 걸린 평균 시간
- `detail: { level, speed, end, maxStep, winner: 'me'|'robot'|null, stopped, turns }`
  - `turns`: `{ who: 'me'|'robot', count, from, to }`, 내 차례는 `via: 'hand'|'button'`, `reactionMs`도
- 화면에 점수·등급처럼 보이는 표현을 쓰지 않는다. "졌어요" 대신 "이번에는 20을 부르셨어요. 다음 판에서 또 해 봐요"

## 하지 말아야 할 것

- `src/core/`를 import 하거나 고치지 않는다. **`ctx`만 사용한다**
- 다른 프로그램 폴더를 import 하지 않는다. 개수 ↔ 손모양 표도 이 폴더 `logic.js`에 따로 둔다
- `logic.js`에서 DOM이나 `ctx`를 쓰지 않는다
