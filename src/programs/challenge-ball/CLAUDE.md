# 도전 활동: 공 주고받기 (challenge-ball)

- **담당:** B
- 이 폴더 밖 파일은 고치지 않는다. 필요하면 이유를 설명하고 A에게 확인받는다 (`src/programs/index.js` 한 줄 등록도 A 확인 뒤)
- 기본 활동 **손운동(STEP 4)의 짝**. 홈의 손운동 카드 아래 "도전" 칸에서 연다 (`dashboard/catalog.js` `CHALLENGES`, #132). **코스에는 들어가지 않는다**

## 목적

화면이 알려 주는 손으로 공을 로봇에게 **건네고**, 로봇이 펴 주는 공을 알려 준 손으로 **돌려받는** 활동.
단계가 오를수록 손 지시가 바뀌고 섞여서, 지시를 보고 기억하며 양손을 번갈아 쓴다.
교육·체험용 활동이며, 치료·예방 효과를 주장하지 않는다.

- 공: AIHand 구성품 40mm 공 **1개** (색은 상관없음)
- 입력은 **화면 버튼뿐**. 어느 손을 썼는지, 공이 잡혔는지는 확인하지 않는다 (센서 없음, 사용자를 믿는다)
- 색 인식·색 이름 부탁은 넣지 않기로 했다 (11/26 B 결정. WonderCam 색 모드는 펌웨어 변경이 필요해서 A 확인 사항)

## 단계 (시작 화면에서 고름, 공통 부품 `src/ui/level-picker.js`)

| 단계 | 손 지시 | 지시 보이기 |
|---|---|---|
| 1단계 | 한 손으로 건네고 받기 (단계를 고른 뒤 오른손·왼손 고름) | 계속 보임 |
| 2단계 | 건네는 손과 받는 손이 다름, 번마다 번갈아 (오른→왼, 왼→오른, …) | 계속 보임 |
| 3단계 | 4가지(오른→오른, 오른→왼, 왼→왼, 왼→오른) 중 무작위, **바로 앞과 같은 지시는 이어 나오지 않음** | 5초(느리게 8초) 뒤 또는 [준비됐어요]를 누르면 가려짐. [다시 보기]로 다시 볼 수 있음 |

- 한 회차 **4번** 주고받기 (`EXCHANGES`, 11/26 B 결정: 6번에서 줄임). 로봇이 공을 쥐는 횟수라서 **10번 이하**로 둔다 (11/23 약지 문제)
- 미리 고른 단계: `ctx.settings.challengeLevel`(1·2·3)이 있으면 그 단계, 없으면 1단계 (`defaultLevel`)
- `ctx.settings.difficulty`(기본 활동용)는 쓰지 않는다. 속도 느리게(`SLOW`)는 "셋, 둘, 하나" 박자·가리기·쥐는 시간·다음으로 넘어가는 시간만 늘린다

## 흐름 (한 번 주고받기)

1. 손 지시 보기: "건네는 손 → 받는 손" 칸 + "오른손으로 건네고, 왼손으로 받아요" → [준비됐어요]
2. 건네기: 로봇 `showPose('PAPER')` → "셋, 둘, 하나" ([공을 댔어요]를 누르면 바로) → `showPose('ROCK')`
3. 받을 손 준비: 약 2초 (`holdBallMs`). 쥔 채로 사용자를 기다리지 않는다
4. 받기: "셋, 둘, 하나" → `showPose('PAPER')`
5. 받은 뒤: [다음으로]·[다시 건네기](공이 떨어졌을 때, 같은 지시로 다시)·[그만하기]. 3.5초(느리게 5초) 뒤 저절로 다음 번
6. 4번 끝: `react('ok')` → `rest()` → 기록 → 끝 화면 ("한 번 더 하기" / "단계 바꾸기")

회차 시작에 `hello()`.

## 꼭 지킬 것 (로봇과 공)

- **공을 쥔 동안(`s.holding`)에는 `showPose('PAPER')` 말고 다른 로봇 명령을 보내지 않는다** (`react`·`hello`·`rest`·다른 손모양은 공이 떨어진다). 칭찬은 공을 돌려준 뒤에
- **끝날 때는 언제나 공을 먼저 돌려준다**
  - [그만하기]를 공을 쥔 동안 누르면: "공을 먼저 돌려 드릴게요. 손을 받쳐 주세요" → "셋, 둘, 하나" → `PAPER` → `rest()` (`giveBack`)
  - 받기 "셋, 둘, 하나" 중에 누르면: 다 센 뒤 손을 펴고 끝낸다
  - 화면을 떠나면(`unmount`): 공을 쥐고 있으면 바로 `PAPER` (공이 떨어질 수 있어도 서보 보호가 먼저)
- `s.holding`은 `ROCK` 명령을 **보내기 전에** 켠다 (그사이 화면을 떠나도 손을 펴게)
- 로봇 `DONE`은 시간이 지나면 오는 응답이다. 공이 정말 잡혔는지는 모른다 (`docs/hardware-check.md`)

## 버튼 입력

- 화면을 넘기는 버튼은 두 번 눌러도 처음 하나만 받는다 (`firstOnly`). [다시 보기]는 화면을 넘기지 않으므로 여러 번 눌러도 된다 (`repeat: true`)
- 로봇이 움직이는 동안 누른 버튼은 줄 서 있다가 다음 기다리기에서 바로 받는다 (`sender`·`s.queued`). 새 화면을 그리면 버리되, [그만하기]는 남겨 둔다
- 손 인식(웹캠)·WonderCam(`ctx.card`)은 쓰지 않는다

## 기록 (`ctx.log.record`)

회차가 끝날 때 한 번. **끝까지 하지 않은 회차(그만하기, 화면을 떠남)는 기록하지 않는다.**

- 공통 필드: `total` 4(주고받기로 한 횟수), `done` 끝까지 주고받은 횟수, `skipped` 0, `avgReactionMs` `null` (맞고 틀림이나 반응 시간을 재지 않음)
- `detail: { level, speed, hand, exchanges }`
  - `hand`: 1단계에서 고른 손 `'right'|'left'`, 2·3단계는 `null`
  - `exchanges`: `{ give, receive, retries, replays }` (손은 지시 기준, `retries` 다시 건네기 수, `replays` 다시 보기 수)
- 화면에 점수·등급처럼 보이는 표현을 쓰지 않는다 ("공을 4번 주고받았어요")
