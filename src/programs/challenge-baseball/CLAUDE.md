# 도전 활동: 숫자 야구 (challenge-baseball)

- **담당:** A
- 이 폴더 밖 파일은 고치지 않는다. 필요하면 이유를 설명하고 확인받는다.
- 기본 활동 **숫자 기억(STEP 1)의 짝**. 홈의 숫자 기억 카드 아래 "도전" 칸에서 연다 (`dashboard/catalog.js` `CHALLENGES`, #132). **코스에는 들어가지 않는다**

## 목적

로봇이 1~5 중 서로 다른 숫자 몇 개를 몰래 정하고, 사용자가 숫자 카드로 순서를 맞혀 보는 활동.
낼 때마다 로봇이 손가락으로 힌트를 준다. 지난 결과를 모아 추리해야 해서 기본 활동보다 오래 생각한다.
교육·체험용 활동이며, 치료·예방 효과를 주장하지 않는다.

- **스트라이크**: 숫자와 자리가 모두 맞은 개수
- **볼**: 숫자는 있지만 자리가 다른 개수
- 숫자 카드: STEP 1과 같은 교구 카드 1~5 (숫자마다 한 장 → 정답 숫자도 서로 다름)

## 단계 (시작 화면에서 고름, 공통 부품 `src/ui/level-picker.js`)

| 단계 | 숫자 개수 | 도움 | 낼 수 있는 횟수 |
|---|---|---|---|
| 1단계 | 3개 | 스트라이크·볼이 모두 0인 판의 숫자를 버튼에 "없어요"로 표시 | 8번 |
| 2단계 | 3개 | 없음 | 8번 |
| 3단계 | 4개 | 없음 | 8번 |

- 미리 고른 단계: `ctx.settings.challengeLevel`(1·2·3)이 있으면 그 단계, 없으면 1단계 (`defaultLevel`). "나의 시작 찾기"로 시작 단계를 정해 두면 대시보드가 이 값을 넣는다
- **나의 시작 찾기 짧은 판** (`ctx.settings.findStart`가 `true`): 단계 고르기 없이 바로 1단계, 낼 수 있는 횟수 5번 (`gameSpec`, `FIND_START_GAME`). 기록은 평소와 같고, 대시보드가 `detail.findStart`를 붙인다
- `ctx.settings.difficulty`(기본 활동용 쉬움·보통·어려움)는 쓰지 않는다. 속도 느리게(`SLOW`)는 로봇이 힌트를 들고 있는 시간만 늘린다

## 흐름 (한 회차 = 한 판)

1. 화면을 열 때 `ctx.card.onNumber` 구독 → core가 WonderCam을 숫자 모드로 바꾸기 시작
2. 단계 고르기 → "시작하기" → `await ctx.card.ready()`
3. 로봇 인사(`hello`) → 숫자를 몰래 정함(`makeSecret`)
4. 숫자 카드를 하나씩 보여 count 개를 냄. 화면 숫자 버튼·Mock 키보드 1~5도 됨. "처음부터 다시"로 이번 것만 비움 (나의 시작 찾기 짧은 판에서는 이 버튼을 보여 주지 않는다, 2026-11-27)
5. 판정(`judgeGuess`) → 로봇이 손가락으로 **스트라이크 개수 → 볼 개수** 차례로 (`countPose`, 0개는 주먹 `ROCK`). 화면에도 "스트라이크 1 · 볼 2"를 글자로
6. 다 맞히면 칭찬(`react('ok')`). 8번을 다 쓰거나 "정답 보기"를 누르면 정답을 화면에 보여 주고 로봇이 손가락으로 차례로 보여 줌
7. 끝 화면: "한 판 더 하기" / "단계 바꾸기". 기록 한 번

## 입력 확정 기준

- STEP 1과 같다: 숫자 카드 하나 = 입력 하나. 들고 있는 카드는 다시 들어오지 않으므로 "카드를 하나 보여 준 뒤에는 잠깐 내려 주세요"
- 이미 낸 숫자를 또 내면 넣지 않고 "N: 이미 낸 숫자예요"
- 내는 단계가 아닐 때(로봇이 힌트를 보여 주는 중 등) 들어온 카드는 버린다

## 화면 (7인치 1280×720)

- 내는 화면: 왼쪽 "지금까지 낸 숫자"(한 줄에 한 번, 8번까지), 오른쪽 이번 칸·숫자 버튼·"처음부터 다시"·"정답 보기"
- 버튼은 오른쪽 칸 안에 둔다. 왼쪽 기록이 길어져도 화면 밖으로 밀리지 않게 (11/20 Mock, 3단계 8번째에서 맨 아래 버튼 690px)
- 숫자 4개면 이번 칸을 68px로 줄인다

## 기록 (`ctx.log.record`)

판이 끝날 때 한 번. 끝까지 하지 않은 판(중간에 화면을 닫음)은 기록하지 않는다.

- 공통 필드: `total` 1, `done` 맞히면 1, `skipped` "정답 보기"로 그만하면 1, `avgReactionMs` 한 번 내는 데 걸린 평균 시간
- `detail: { level, speed, count, secret, solved, stopped, tries, history }`
  - `history`: 낼 때마다 `{ guess, strike, ball, inputVia: ['card'|'button' 숫자마다], reactionMs }`
- 화면에는 "N번 만에 찾으셨어요"처럼만 쓰고 점수·등급처럼 보이는 표현을 쓰지 않는다

## 하지 말아야 할 것

- `src/core/`를 import 하거나 고치지 않는다. **`ctx`만 사용한다**
- 다른 프로그램 폴더(`step1-memory` 등)를 import 하지 않는다. 숫자 ↔ 손모양 표도 이 폴더 `logic.js`에 따로 둔다
- `logic.js`에서 DOM이나 `ctx`를 쓰지 않는다
- "틀렸습니다", "실패" 대신 "함께 정답을 확인해 볼까요?"처럼 쓴다
